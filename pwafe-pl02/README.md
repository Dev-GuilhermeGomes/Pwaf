# PWAFE PL02 - Ementa de hoje

Aplicação React + TypeScript para apresentar uma ementa por categorias, com preços, etiquetas, alergénios e filtro vegetariano.

## Como correr

```bash
npm install
npm run dev
```

Para validar a compilação:

```bash
npm run build
```

## Estrutura

```text
src/
  components/   Componentes reutilizáveis da ementa
  data/         Dados dos pratos
  App.tsx       Composição da página e filtros
  types.ts      Tipos Categoria e Prato
```
